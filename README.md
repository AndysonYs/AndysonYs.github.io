

# AndysonYs.github.io

This repository hosts the source code for the personal website located at [AndysonYs.github.io](https://AndysonYs.github.io).

## Project Overview

Based on the repository configuration, this project is set up for development using **Python 3.7**. It includes specific configuration for IDE integration, code formatting, and style inspections.

### Tech Stack & Tools

*   **Language:** Python 3.7
*   **IDE:** PyCharm / IntelliJ IDEA
*   **Formatter:** Black
*   **Style Guide:** PEP8 (with specific naming inspection rules)

## Installation & Usage

### 1. Clone the Repository

```bash
git clone https://github.com/AndysonYs/AndysonYs.github.io.git
cd AndysonYs.github.io
```

### 2. Configure Environment

To ensure consistency with the project settings, please configure your development environment as follows:

1.  **Python SDK:** Install and select **Python 3.7** as the project interpreter.
2.  **Formatter:** Configure **Black** as your code formatter.
3.  **IDE Settings:** If using PyCharm, import the included `.idea` settings to enable PEP8 inspections and module management.

## Deployment

This repository is configured as a GitHub Pages site. Changes pushed to the default branch will typically trigger an automatic deployment.
